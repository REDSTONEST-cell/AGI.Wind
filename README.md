# AGI.Wind 本地服务端还在开发

当前已运行服务端基础版本与可用的陪伴客户端，完整 AI 伴侣仍在实施。部署顺序：先本机测试，之后再迁移 NAS。

**聊天客户端：http://127.0.0.1:18440/**（依赖状态页在 `/status`）。本机访问时浏览器会自动建立 HttpOnly 会话，无需访问令牌；服务器与客户端分开部署时，在侧栏「连接」填写服务器地址与客户端密钥（默认 `123456`，正式使用前请更换）。界面为控制台式布局，视觉参考 [qq-bridge](https://github.com/Derpyu520/qq-bridge)（MIT，仅借鉴设计语言与组件模式，未复制其页面/脚本）：

- **界面结构**：234px 固定侧栏（陪伴 / 她的档案 / 系统三组导航）、76px 顶栏（面包屑 + 服务状态 + 浅深主题 + 刷新），主区使用页面标题、指标条（归档/连接/档案）、卡片网格、表格、状态胶囊与粘性保存栏；对话页保持单一聊天窗口，右侧可拉出运行日志抽屉。支持 `#/chat`、`#/soul` 等哈希路由、浏览器前进后退、浅色/深色/跟随系统主题，以及 1024/390 响应式布局。
- **运行日志**：对话页「日志」按钮从右侧拉出**终端式系统日志**抽屉：深色等宽输出、自动跟随/暂停、全部/系统/活动/错误筛选、清空；系统行来自 Gateway 的 stdout/stderr（服务端已脱敏），活动行来自当前页面操作，最多保留 1500 行。桌面端压缩对话区并排显示，手机端全屏。
- **单会话**：主界面永远只有一段进行中的对话；旧对话进入「对话归档」只读保留，可恢复为当前对话。对话页的「⋯」菜单提供重命名、归档并开始新对话、永久删除并开始新对话，全部为页面内控件，不使用浏览器原生 `prompt/confirm`。
- **删除语义**：归档页和「⋯」菜单的删除都是永久删除，会清除对话事件、附件引用及由它产生的记忆来源，无法恢复。
- **模型设置**：按能力分为 6 张能力卡——计划/对话模型、语音转文字、文字转语音、嵌入、重排序、识图；左侧提供商源列表、右侧详情（Base URL、模型 ID、API Key、测试、删除）。对话、识图和本地 Breeze 文字转语音已接入真实适配器；其余标注「待接入」。
- **灵魂档案**：角色的一生设定，带版本号、字段数、档案体积与头像上传；名字和头像显示在气泡外。保存时检测重复的旧格式长文本。
- **记忆**：关键词检索与带来源的纠正；服务商密钥只写服务端，页面仅显示脱敏状态并热加载。
- **连接**：支持同源浏览器（cookie + CSRF）与独立客户端（Bearer 客户端密钥 + CORS 白名单）两种形态；连接页以指标卡展示服务、数据库、模型与档案格式。
- **图片与表情包（v7）**：输入框左下角“＋”选择图片，或 Ctrl+V 粘贴剪贴板图片；上传后在输入框内预览，可移除，最多 4 张，支持纯图片发送。图片回合按观察→回答→二次思考→真实收藏/模仿编排；前后两组处理轨迹可折叠，历史保留图片；新增 `#/stickers` 上传、改名、标签、隐藏/恢复和删除。
- **本地语音回复（v8）**：接入本机 Breeze-TTS-2 的 `yuwan` 克隆音色。输入框底部有独立「语音」开关：关闭时按可调概率（默认 30%）随机带语音，打开后每条有正文的回复都带一条语音。语音是独立助手气泡，支持播放/暂停、时长、生成状态，历史和归档可回放；文字保留。提示词要求她第一行写隐藏情绪标记（如 `[情绪:开心]`），服务端在流式输出中剥离，再映射成开心/难过/撒娇等固定语气；只有标记缺失时才用受限“语气导演”兜底。不重新训练、不重新下载模型。启动由 `scripts/start-voice.ps1` 管理，日志在 `data/voice.*.log`，失败不影响文字聊天。
- **聊天与日志调整**：聊天区扩大、头像放大、侧栏顶部品牌区移除；系统日志含“处理”筛选，显示真实思考与工具状态。日志栏左边界可拖动，支持方向键、双击重置，刷新记住宽度；手机端全屏。思考只进入档案和当前页面内存日志，不写 Gateway stdout 或 localStorage。
- **双方头像**：在「灵魂档案」分别设置她的头像和「基本档案 → 你的头像」。选图后可拖动/缩放裁剪成 512×512，再确认上传，保存档案后生效。头像预览固定为 88px，并处理异步重绘，避免重复叠图；日志“处理”中也能查看每条回复正文，刷新后从已存轨迹恢复。
- **过程显示位置**：按最新要求，思考与工具过程只出现在日志栏；当前聊天和归档回看仅显示正文与图片，不再显示处理轨迹折叠块。
- **分段回复**：按 `。！？!?` 和换行分成独立气泡，去掉句末分隔标点，保留开头的问号/感叹号；逗号、顿号留在句内，英文句点保留以保护文件名/编号/小数。代码与 URL 内部标点受保护，图片独立成条；历史/归档按同一规则回看。服务端原文与上下文仍完整保存。
- **输入区优先**：聊天页面固定在可视区内，只滚动消息历史；提示条移到顶部，空状态不覆盖输入；日志在桌面并排，手机端给底部输入区留出空间。

可以直接双击：

- `启动本地服务.cmd`：启动本项目 PostgreSQL 和 Gateway（只监听 127.0.0.1），不重复创建角色。
- `启动服务端(局域网).cmd`：以 `0.0.0.0` 监听，供局域网内其他设备上的客户端连接。
- `查看本地状态.cmd`：读取各依赖状态，局域网模式会列出可用访问地址。
- `停止本地服务.cmd`：正常停止服务和数据库，保留数据。
