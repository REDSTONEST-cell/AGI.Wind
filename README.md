# AGI.Wind 本地服务端

当前已运行服务端基础版本，完整 AI 伴侣仍在实施。部署顺序：先本机测试，之后再迁移 NAS。

本地网页：**http://127.0.0.1:18440/**，可直接查看服务状态。此页面是状态入口，聊天客户端尚未接入。模型尚未配置时，底层 `/health/ready` 返回 HTTP 503 degraded，主页仍正常返回 HTTP 200 并展示待配置状态。

可以直接双击：

- `启动本地服务.cmd`：启动本项目 PostgreSQL 和 Gateway，不重复创建角色。
- `查看本地状态.cmd`：读取各依赖状态。
- `停止本地服务.cmd`：正常停止服务和数据库，保留数据。

已实现原文归档、幂等、人格版本、关键词检索、纠错、SSE、基础导出/恢复和删除账本。62 项测试通过；真实厂商、Letta、向量、语音、声音训练和正式客户端未验收。
