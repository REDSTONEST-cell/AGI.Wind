# Nagi 使用说明书

Nagi 是一个住在你电脑里的 AI 伴侣。

你可以和她聊天、给她发照片、听她说话、和她打电话；也可以把 QQ 接上，让她在你的群聊和私聊里出现。她的记忆、人格和大部分数据都留在你自己的电脑里，不需要把生活交给云端。

这份说明是写给使用者的，不需要懂代码也能开始。

---

## 一分钟认识她

打开之后，你会看到一个类似聊天软件的界面。你主要会用到这些地方：

- **陪伴**：和她聊天；发文字、图片、表情。
- **她的档案**：她叫什么、是什么样的人、你们是什么关系、她长什么样。
- **记忆**：她记得关于你的事情；你可以查看、纠正或删除。
- **表情包**：她收藏和使用的表情包。
- **对话归档**：以前的对话会留在这里，可以恢复，也可以永久删除。
- **设置**：模型、语音、QQ、主动消息和外观。

她可以做到：

- 像人一样分段回你，而不是每次都发一大段
- 在你想听的时候用语音回复，也可以接电话式实时通话
- 看懂你发来的图片，收藏她喜欢的表情
- 在 QQ 私聊或群聊里和你说话
- 在你不找她的时候，自己想一想；也可以主动来找你

---

## 第一次打开

### 已经安装好的版本

双击 **`启动本地服务.cmd`**。

等窗口里出现访问地址后，用浏览器打开：

**http://127.0.0.1:18440/**

第一次打开会自动准备数据库和角色。以后每次使用，双击这个文件即可。

用完想关闭时，双击 **`停止本地服务.cmd`**。直接关掉窗口通常不会丢数据，但正常停止更稳妥。

### 想让手机或另一台电脑访问

双击 **`启动服务端(局域网).cmd`**，然后在同一 Wi-Fi 下用手机浏览器打开电脑的局域网地址。

具体地址可以双击 **`查看本地状态.cmd`** 查看。

> 不要把服务直接暴露到公网；如果要远程访问，建议使用 VPN、内网穿透或带 HTTPS 的反向代理，并先更换默认密钥。

### 从 GitHub 下载源码

如果你拿到的是源码而不是安装包，需要先准备：

- Windows 10 / 11
- Python 3.12
- 本地 PostgreSQL
- 一个可用的对话模型（在设置里填写）

第一次安装请按 [运维说明](docs/ops/runbook.md) 操作。装好之后，日常使用仍然只需要双击启动脚本。

## 日常聊天

- 在输入框输入文字，按 **Enter** 发送，**Shift + Enter** 换行。
- 她回复时，文字会逐字出现；正在生成时可以停止。
- 她可能只回一条，也可能回好几条。这是她根据内容自己决定的，不是固定三段。
- 点消息旁边的语音按钮，可以听这一条；历史记录里的语音也可以回放。
- 对话页的「日志」可以看到她这一轮怎么想、用了什么工具。日志只是给你看的，不会打扰聊天。

### 发图片

- 点输入框左下角的 **＋** 选择图片。
- 也可以直接 **Ctrl + V** 粘贴剪贴板里的图片。
- 一次最多 4 张，可以只发图片不写字。
- 她会先看图片，再回答；如果她喜欢，会收藏成表情包。

### 对话归档与删除

- 「⋯」菜单里可以重命名、归档并开始新对话。
- 归档不是删除；归档对话可以在「对话归档」里恢复。
- 在归档页或菜单里选择**永久删除**后，对话、附件和由它产生的记忆来源会被清除，**无法恢复**。

---

## 让她说话

语音是可选功能，需要电脑上已经准备好本地语音服务。

- 在语音设置里可以选择她已经学会的音色。
- 打开「语音」开关后，她会在有正文的回复里带语音。
- 即使没打开开关，你也可以直接对她说：
  - “发条语音”
  - “我想听你说话”
  - “用语音回我”
  - “唱两句”
- 语音会分段排队播放；如果浏览器拦住了自动播放，点一下页面或消息上的播放按钮即可。
- 语音服务没启动时，她仍然可以正常打字，不会影响聊天。

### 和她打电话

在实时通话界面打开麦克风，就可以像打电话一样说话；她的回复会边生成边播放，也可以打断她。

第一次使用时，浏览器会询问麦克风权限，选择允许即可。

---

## 修改她的样子和声音

### 她的档案

在「她的档案」里可以设置：

- 她的名字
- 她是什么样的人、说话方式、和你的关系
- 她的头像
- 你的头像和称呼
- 你们之间的约定和重要回忆

保存后，新对话会使用最新档案。已经归档的旧对话不会被改写。

### 声音

在语音设置里选择已保存的音色，然后点「试听」。

如果想让她用新的声音，需要先在本地语音服务里准备好参考音频和对应文字；这部分属于进阶配置，详见 [运维说明](docs/ops/runbook.md)。

---

## 记忆

她会记住和你有关的事情，也会在聊天时自然用上这些记忆。

- 「记忆」页可以查看她记得什么，也可以纠正或删除。
- 她不会凭空编造“你以前说过”的事情；没有来源的记忆会被标记。
- 私聊和群聊的记忆是分开的；群聊不会继承你们私下的关系、承诺和私密内容。

---

## 使用 QQ

QQ 功能需要额外的 OneBot 实现，例如 SnowLuma；Nagi 本身不包含 QQ 客户端。

在设置里填写：

- 机器人 QQ 号
- 主人的 QQ 号
- OneBot 的 WebSocket 地址和 token
- 要启用的群

连接成功后，她可以在私聊和群聊里回复。群聊里她会：

- 看到发言人的名字
- 对连续消息做合并理解
- 只在被叫到、被回复或话题相关时说话
- 不把群友当成你，也不泄露你们的私聊内容

QQ 的登录、掉线和 OneBot 配置由对应的 QQ 客户端负责。

## 主动找你与独处思考

这些功能都在设置里，默认比较克制，可以随时关闭。

### 主动消息

打开后，她可能在你一段时间没说话时来找你。

你可以限制：

- 最短沉默多久才主动
- 两次主动之间至少隔多久
- 每天最多几次
- 哪些时段不要打扰你

### 独处思考

你回复之后，她可以在后台想一想刚才的对话，形成自己的判断。独处思考默认只写入日志和档案，不会自动变成发给你的消息。

## 数据、备份与隐私

- 你的聊天、人格、记忆和语音数据默认保存在本机的 `data/` 目录。
- 模型请求只会发给你在设置里配置的模型提供方。
- 备份时，关闭服务后复制整个 `data/` 目录即可。
- 不要把自己的 `data/`、配置文件里的密钥、QQ token 或证书上传到公开仓库。
- 删除对话是永久删除；如果只是想暂时不看，请使用归档。

## 常见问题

**打开网页后没有反应？**

双击 `查看本地状态.cmd`，确认 Gateway 和数据库都在运行；再试一次 `启动本地服务.cmd`。

**她一直不回我？**

检查设置里的对话模型是否配置正确，以及模型服务是否可用。也可以打开对话页「日志」看错误信息。

**没有声音？**

确认语音服务已启动、语音开关已打开，并检查浏览器是否允许自动播放。可以先点消息上的播放按钮测试。

**手机打不开？**

确认手机和电脑在同一 Wi-Fi，使用 `启动服务端(局域网).cmd`，并用 `查看本地状态.cmd` 里显示的局域网地址访问；同时检查 Windows 防火墙是否允许该端口。

**她记得的事情不对？**

去「记忆」页找到对应记忆，纠正或删除。她不会因为删除记忆就篡改已经发生的聊天记录。

**删掉的对话还能恢复吗？**

不能。归档可以恢复，永久删除不可恢复。
