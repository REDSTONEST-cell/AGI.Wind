        Agent 能力

        让她按需要查询记忆、挑选表情包、检索网络资料、访问电脑文件或执行命令行。工具过程只在系统日志显示。

        工具与权限

        电脑文件访问

        文件工具的权限边界。“逐次批准”会在每次操作前弹出批准窗口。

        Windows 管理员权限

        命令行执行

        让 Agent 在网关所在电脑执行命令（Windows 用 cmd，其他系统用 sh）。

        参考 AstrBot 的 Agent 电脑能力：默认关闭；Windows 没有本机进程沙箱，命令以网关进程用户权限运行，逐次批准弹窗是唯一的人工闸门。默认工作目录为 data/agent-workspace，不要执行破坏性或长期驻留命令。

        调用限制

        限制每轮回答中工具的调用规模与耗时。
