# QQ 主人私聊接入记录

## 已实现

- 连接页增加QQ开关、主人/机器人号码、连接令牌、分段间隔、状态与会话绑定。
- OneBot v11 Universal反向WebSocket：`/api/v1/integrations/qq/ws`。复用FastAPI，不新增另一套机器人框架依赖。
- 参考AstrBot的平台适配边界与NoneBot的鉴权/echo回执模式，未复制上游实现代码。外部QQ协议端保持独立，兼容SnowLuma。
- 仅主人好友私聊进入当前绑定且已授权的活动会话；群、其他用户、机器人自发消息、过期历史忽略。
- 复用人格、记忆、Agent审批；正文按现有规则分条，图片独立发送；思考/工具轨迹不发送到QQ。
- 入站QQ CDN图片只接受HTTPS、验证公网DNS并固定连接IP与TLS主机名，限4张/每张10MiB，经AssetStore验证真实格式后入档。
- 消息ID映射稳定请求UUID，数据库与连接内去重；有界队列，API回执失败不自动重发。断线不重放旧回复。
- `/stop` 停止QQ当前生成并清空待发送/待处理消息；网页全局Stop也停止QQ交付。QQ局部停止只撤销该生成的审批。

## 最小验证

一次最终针对性运行：27 passed（QQ协议、真实PostgreSQL+模拟OneBot WebSocket往返、Agent设置与客户端设置）。合成提供商，无付费模型调用，无真实联系人测试消息。覆盖错误凭据、陌生人/群忽略、分段、不泄露思考、重复上报、排队停止、审批隔离和并发连接准入。

独立只读审查发现并修复停止队列竞态、审批撤销范围和连接准入竞态。桌面管理页已检查；真实QQ消息与媒体效果由用户的一次私聊验收确认，不反复发测试消息。

## 使用与边界

1. 保持QQ客户端、SnowLuma和AGI.Wind服务运行。
2. 在网页“连接 → QQ”确认已连接，使用主人QQ向机器人发一条普通私聊。
3. 更换/归档网页对话后，在连接页重新保存绑定；修改令牌后同步更新接入端。
4. 首版不支持群聊、QQ语音消息收发、撤回同步、历史补投或跨机器管理QQ进程。文字回复待本轮生成完成后分条发送。
