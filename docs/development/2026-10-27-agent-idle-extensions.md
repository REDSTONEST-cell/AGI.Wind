# QQ 追话、独处工具、通话插话与记忆检索

后续状态以 [功能联动审计](2026-10-27-integration-audit.md) 为准：已补齐 call_id、全局停止、主动消息渠道和群记忆后台等连接；下文保留本阶段历史测试记录。

本次对应功能清单 1、2、3、5、6。保留现有档案、模型和记忆权限，不引入完整机器人框架。

## 已实现

- QQ 私聊和允许的群支持回复后独处追话。源请求以 `qq-private:bot:owner` / `qq-group:bot:group` 固定目标；旧的无目标记录不猜测收件人。每次模型调用、归档和逐段发送前检查有效设置、绑定、白名单、最新消息和取消状态。群上下文使用 `SceneScope(group, binding.id)`，不继承主人关系和私聊记忆。发送与普通 QQ 回复串行；新消息和 Stop 取消追话。
- 独处时可查询记忆、表情包、网页搜索及网页抓取。只读白名单，不提供文件、命令或直接发送工具。默认每次最多 2 次工具调用，可设 0–3；工具每次最多 5 秒。工具轮消耗已有模型轮数，最后一轮强制最终决定，不增加隐式模型调用。仅供应商白名单支持的输出参数限制为 512 tokens。
- 追话可使用本轮搜索选中的表情包图片，以及已有本地 TTS。遵守语音总开关与概率，不额外调用情绪导演模型。附件写入档案并建立 asset_refs，网页和 QQ 使用既有媒体渲染与发送格式。QQ 发送失败不自动重试，档案可能保留未成功外发的消息，运行状态记录失败。
- 群接话规则优先；仅活动话题内的模糊追问使用严格 JSON 分类，置信度至少 0.85。每群冷却 60 秒、全局每天最多 6 次、8 秒超时、最多 128 输出 tokens；无可强制的 token 上限则观察。持久化最多 100 群近期参与者、时间和预算，不保存正文。目前每群仍是一个近期话题，尚未做多话题并行。
- 通话开启浏览器回声消除，播放时仍持续上传麦克风。检测说话立即停止旧播放、模型流与 TTS，epoch 隔离迟到数据，speech credits 限制排队。实际手机麦克风和回声效果需现场验收；既有 call_id 服务端绑定契约仍未完成。
- 记忆使用 USearch HNSW 本地索引；按 512 条分页冷建全部合格向量，取消一万条截断。完全相同向量共用图节点；查询后复核来源、修订、内容与群权限，失效候选可扩展搜索，故障回退关键词。只增加明确饮料偏好谓词别名，不进行模糊 value 合并。

## 设置与资源限制

主动消息页新增 QQ 追话、独处工具、追话媒体、工具次数设置；还受原有主动总开关、轮数、每日次数、安静时段和 Agent 工具开关限制。工具内容只进入本次临时模型上下文，运行日志只记工具名和状态。

ANN 热查询仍读取 O(n) 紧凑元数据并执行数据库资格检查；首次构建和修订后重建有开销。绕过正常 writer 修复数据库且不改变 revision/hash 时，先前不合格对象可能暂时漏召回，应清理进程缓存。没有取消安全复核。

## 验证边界

不调用付费模型、不向真实 QQ 联系人发测试消息、不使用私人聊天做性能测试。

- 通话前端 Node 14/14；QQ 注意力 32/32；记忆专项 45 项通过。
- 新增 QQ idle 验证 4 项通过：目标投递、换绑定不调用模型、群 SceneScope、附件引用。
- 独处工具 5 项通过：白名单、预算、禁止调用、历史配对及无 Agent 配置回退。
- 全量一次得到 428 passed、9 failed、3 skipped；其中 4 个记忆旧测试已改为显式推进到可执行时间，归档往返需在 app 工作目录运行。剩余已知失败为 call_id 缺失及 3 个仍按句号断句的语音旧测试；生产分段规则按模型换行，不为旧测试改变。
