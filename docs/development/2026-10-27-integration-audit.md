# 2026-10-27 功能联动审计

目标：检查功能边界是否连接，而不是只证明每个模块能单独运行。工作目录为桌面 AGI.Wind，保留既有未提交改动。没有调用付费模型、没有向真实 QQ 联系人发送测试消息。

## 查明并修复的断点

| 边界 | 修复前证据 | 修复后行为 |
| --- | --- | --- |
| 通话 → HTTP 聊天 | realtime 分支调用未安装的 submit_call_chat，真实入口返回 500；票据不返回前端需要的 call_id | 票据签发 call_id，服务端登记会话与账号绑定；只允许已连接通话提交；前端发送真实 call_id；未连接/挂断后拒绝 409 |
| 通话 → 生成生命周期 | WebSocket 只取消 ASR/TTS，缺少所属聊天生成登记 | 插话、挂断、断连和全局 Stop 取消该通话未完成的生成；不会取消普通文字聊天；通话期间不排独处追话 |
| Stop → 长空闲主动消息 | 全局停止后主动模型任务仍在等待 | 主动请求登记 Actor 与子任务；Stop 取消在途请求并暂停自动主动消息，直到新用户事件到来；取消单次发送不杀掉调度循环 |
| 主动消息 → QQ | 长空闲主动消息只写网页，独处服务另有一套 QQ 投递代码 | 两者共用 ProactiveService.deliver，按来源 QQ 目标发送并逐段校验；主动请求保留渠道标识，下一次不会丢失 QQ 目标 |
| 主动消息 → 档案／计数 | 档案写入和每日计数在两个事务中 | 归档、附件引用、主动计数同一事务；锁内验证上下文、安静时间和日上限；QQ 外发失败不盲目重试 |
| 独处 → 人格／记忆 | 完成模型调用后只验证新消息，不验证资料版本 | 绑定上下文 memory_revision/persona_version；每轮及归档事务内重查，旧资料不投递；保留群发言者标签 |
| 独处媒体 → 设置 | 查询后即使关闭发送表情包仍可附图；工具失败在页面显示完成 | 发图复核实时 Agent/查询/发送开关，独处工具开关在执行前重查；开始、完成、失败进入日志正确状态 |
| 记忆后台 → 群场景 | 每角色只取一个窗口，群窗口以普通 Scope 表达 | 私聊与每个启用群分别构造场景并索引；群使用 SceneScope/binding_id，主人摘要只由主人任务生成 |
| 群观察 → 主人记忆 | 未触发回复的主人群发言仅走成员任务，因主人身份又被成员提炼排除 | 主人观察发言进入主人延迟队列；具名其他成员进入成员队列；匿名不进入长期身份记忆 |
| 主人摘要 → 来源隔离 | 摘要的 source_owned_clause 只验证账号窗口，未排群成员；缺发送者被等同主人 | 摘要和提炼共用身份筛选；缺身份只兼容旧私聊，群来源必须明确主人；向量 SQL 资格门与 Python 来源复核同步 |
| QQ／通话断连 → 清理 | 两个 QQ WebSocket 回归稳定复现 CancelledError，清理在 ASGI 已取消作用域内被再次中断 | 按 AnyIO 的 shutdown shield 模式完成所属资源清理，再维持取消语义 |

来源隔离只做资格收紧，不删除原始档案。对当前数据库执行了不含正文的来源计数：活跃主人记忆中，群成员／匿名群来源的待复核条目为 0；没有批量改写现存记忆。

## 统一后的路径

文字和 QQ 都经 GenerationService、ContextBuilder、AgentRunner、档案与记忆 outbox。独处读取相同人格、记忆场景和 StationTools，只暴露只读白名单；媒体发送沿用 QQBridge。两种主动消息共用归档、计数、取消和外发检查。网页 Stop 与主人 QQ Stop 调用同一停止入口。

语音经同一聊天档案、人格和记忆服务，但 realtime 仍为低延迟流式路径，不进行阻塞的 Agent 工具规划。通话的 TTS 不另存普通语音附件；语音控制与普通语音消息的播放路径仍有区别。

## 联动验证

新增 test_system_links.py 覆盖真实服务组合，仅替换供应商和 OneBot 网络 I/O。完整场景为：聊天结束 → 两个只读工具查询记忆及表情包 → 最终 JSON 决定 → QQ 文字及图片 → 附件归档及 asset_refs → 仅日志显示思考和工具状态。

其余场景验证未连接通话拒绝、挂断阻止迟到提交、普通聊天不误停、Stop 终止主动请求但保留调度、资料版本变化阻止投递、每群索引、摘要身份隔离、观察发言路由及媒体开关联动。

旧语音测试的三处单行句号分段样例已改为按模型换行表达多条消息，以匹配当前用户选择的规则；没有为测试改变生产分段行为。最终自动验证数字见本文件末尾。

## 仍有边界

- 通话使用同一人格记忆，但文件、命令、联网等工具操作仍走文字聊天。
- 长空闲主动消息仍只生成短文字；独处追话可使用工具和媒体，二者共用投递生命周期。
- 群接话仍为每群一个近期话题，没有群内多话题并行；分类预算保持每天 6 次。
- ANN 查询仍有 O(n) 紧凑元数据检查；未完成大型多群与长期压力验证。
- 真实手机麦克风、扬声器回声与真实 QQ 语音／图片往返仍需设备侧验收；模拟通过不代表这些已完成。

断连清理参考：[AnyIO 官方 cancellation / finalization](https://anyio.readthedocs.io/en/stable/cancellation.html)。没有引入新机器人框架或复制第三方代码。

## 后续：主动消息同步主人 QQ

主人绑定窗口在网页产生的长空闲主动消息和独处追话，也同步到已配置的主人 QQ 私聊；不再要求上一条消息来自 QQ。网页仍只归档和显示一次，不额外调用模型；群追话保持原群目标，不转发到主人私聊。沿用「主动消息同步到 QQ」开关。
