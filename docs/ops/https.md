# 公网 HTTPS

如果你想让客户端从外网访问，建议使用自己的域名和 HTTPS 反向代理，而不是直接暴露 Gateway 端口。

推荐结构：

```text
浏览器 / 手机
      │ HTTPS
      ▼
Caddy / Nginx（域名证书）
      │ HTTP 127.0.0.1:18440
      ▼
AGI.Wind Gateway
```

要点：

- 域名直接指向运行 Gateway 的机器，或指向同一内网中的反向代理。
- 反向代理只转发到 `127.0.0.1:18440`，不要开放数据库、TTS、ASR、记忆服务的端口。
- 证书、私钥、ACME 账号和 DNS API 凭据不要提交到仓库。
- 如果需要 DNS-01 自动签发证书，建议把 DNS 凭据保存在本机受保护的配置或系统凭据中，不写入仓库。
- 公网访问时务必更换默认客户端密钥，并确认防火墙只放行必要端口。
- 手机外网、麦克风和实时通话需要单独验收，不能只用“本机能打开域名”替代。

配置和证书的运行文件放在本机 `data/` 或系统配置目录，均不应进入 Git。
