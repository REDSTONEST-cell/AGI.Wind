# QQ 多媒体最小适配

目标：私聊和已授权群聊接收图片、表情包及语音；回复可发送语音及图片表情包。

## 设计与实现

- [x] `integrations/qq.py`、`qq_groups.py` 保留图片文件标识和语音消息标识。
- [x] 图片复用 AssetStore 和现有 VisionAdapter；缺少 URL 时调用 OneBot `get_image`。
- [x] 兼容 QQ CDN 报出的 HTTP 地址，仅对白名单域名升级 HTTPS；保留公网 DNS/IP 固定、防重定向、大小和真实格式校验。
- [x] 语音调用当前 SnowLuma 已实现的 `get_record_text(message_id)`；依据原始 QQ 消息转写，不访问消息提供的本机路径，也不伪造内容。
- [x] 转写结果带 `[语音转文字]` 标签进入原有聊天/成员记忆隔离流程。原始语音本次不存档；不是重新部署本地 ASR。
- [x] QQ 输入语音或文字要求“语音”时申请 always；其余 auto，服从现有全局语音开关和概率。
- [x] 等待本轮后台合成，最多 120 秒，可被 Stop 取消；语音以 record/base64 发送，图片表情包以 image/base64 发送；文字保留作为回退。
- [x] 新增 `test_qq_media.py`，验证纯语音私群解析、实际转写输入、缓存图片、音频/表情包输出、等待本轮合成、CDN 兼容。

## 验证边界

针对 QQ 协议、注意力、私聊与群聊的 31 项自动测试通过；测试使用替身，不调用付费模型、不主动向联系人发消息。
真实 QQ 语音识别依赖 QQ/SnowLuma 的转写返回；语音发送依赖 OneBot 的音频编码能力和已启用 TTS。
实际图片识别依赖已配置视觉模型。真实 QQ 图片/语音往返未冒充已验收。
