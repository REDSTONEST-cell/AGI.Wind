# QQ OneBot Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让主人通过QQ私聊使用同一个鱼丸。
**Architecture:** FastAPI universal reverse WebSocket 接入外部 SnowLuma，薄适配层调用现有生成与档案服务；配置使用 SecretStore 和持久设置。
**Tech Stack:** 现有 Python 3.12、FastAPI、SQLAlchemy、httpx、原生JS，无新增框架依赖。
**Spec:** docs/superpowers/specs/2026-10-26-qq-onebot.md

## Global Constraints

- 默认关闭，仅主人好友私聊，群聊忽略。
- 不复制上游代码，不存QQ密码，不公开令牌，图片下载拒绝内网。
- 沿用当前活动会话，思考仅日志；外部发送只在明确收到主人消息时发生。

## Review Focus

- 错误令牌、机器人号或用户号不得调用模型。
- 重复消息与重连不得重复生成；echo超时不得盲目重发。
- 生成等待不能阻塞WebSocket回执；/stop在繁忙时仍优先处理。
- 网络图片、配置变更和断开连接必须收敛资源。
- QQ协议模拟测试不等于真实QQ登录成功。
