# QQ OneBot 接入设计

用户批准参考 AstrBot 开始接入；首版仅主人私聊，群消息忽略。SnowLuma 独立运行，AGI.Wind 提供 OneBot v11 universal 反向 WebSocket，不包含 QQ 协议实现或登录凭据。

## 调研与取舍

- AstrBot（AGPL-3.0，GitHub pushed_at 2026-10-25）：CQHttp 平台适配器将协议事件转换为框架消息，私聊和群聊分别发送。依赖 aiocqhttp、AstrBot 事件和消息组件，不能直接粘贴独立使用。
- NoneBot adapter-onebot（MIT，pushed_at 2026-10-09）：按 X-Self-ID 验证连接，Bearer 鉴权，echo 关联 API 回执，消息处理任务独立于接收循环。依赖 NoneBot driver/bot/collator，整套引入会增加第二套运行时。
- aiocqhttp（MIT）：AstrBot 使用的成熟传输库，内部包含 Quart/aiohttp；本项目已有 FastAPI/WebSocket，首版按上述已验证边界编写薄适配层，复用现有服务，不移植上游代码。
- SnowLuma：源码可见非商业许可，原生组件另有专有条款；保持外部程序，兼容 OneBot v11，可后续更换实现。

已知边界：消息回执超时不能盲目重发；重连上报会重复事件；不能让生成阻塞回执接收；媒体文件在不同进程间不能直接使用未授权 URL；群会话与主人人格不得错误绑定。首版只接主人私聊，避免跨用户记忆混用。

## 契约

- 设置位于连接页：开关、主人QQ、机器人QQ、当前活动会话、令牌更新、状态刷新。默认关闭，必须配置号码和32字节以上令牌。
- 仅配置的机器人可建立 universal 连接，且只处理主人好友私聊；群、其他用户、自发消息、历史消息忽略。
- 主人消息进入当前已授权活动对话，复用人格、记忆、生成和 Agent 批准。请求UUID由机器人QQ与OneBot消息ID确定，重复上报不得重复生成或发送。
- 文本按现有 split_reply 分段，图片独立消息。思考和工具轨迹仅日志。/stop 优先取消当前 QQ 生成与后续发送，审批仍在网页。
- 收发队列和帧大小有界；失连取消该连接的交付，重连不自动重放已发送消息；回执失败标记失败，不自动重试。
- 只接受文本和最多4张经过地址、重定向、大小和真实类型校验的HTTPS公网图片；拒本机/内网地址，下载结果经 AssetStore 授权存档。
- 首版不部署外部QQ客户端、不主动发给联系人、不启用群聊。真实QQ登录和收发验收与模拟协议验收分别报告。
